# Geography starter data

The country list and Kenyan location names contain information from the [Countries States Cities Database](https://github.com/dr5hn/countries-states-cities-database), distributed under the [Open Database License 1.0](https://opendatacommons.org/licenses/odbl/1-0/). The starter data includes all 47 Kenyan counties and a starter selection of cities and towns.

Additional towns are drawn from the [State Department for Lands](https://www.lands.go.ke/land-registries), [Vihiga County](https://vihiga.go.ke/explore/towns/mbale-town), and [Elgeyo Marakwet County](https://www.elgeyomarakwet.go.ke/docs/HTML/toc510645891.html).
